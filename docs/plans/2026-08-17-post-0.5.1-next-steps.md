# Post 0.5.1 Model Runtime Next Steps Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** After the 0.5.1 release, protect the now-working local model pipeline while preparing Subcast for faster model iteration through evidence-based capability, benchmark, and policy layers.

**Architecture:** Treat 0.5.1 as the stable model-control baseline. First run a post-release stability gate, then add model capability and benchmark infrastructure in non-behavior-changing commits, and only after that enable task-level model policy decisions. Keep llama.cpp as the only default backend in this cycle.

**Tech Stack:** Nuxt 4/Nitro, TypeScript, better-sqlite3, llama.cpp `llama-server`, whisper.cpp/SenseVoice, Vitest, Electron packaged sidecars.

---

## Decision

Do not immediately start another large behavior-changing model rewrite after 0.5.1.

Recommended order:

1. Stabilize and observe 0.5.1.
2. Add capability metadata and benchmark tooling without changing runtime behavior.
3. Add task model policy in dry-run/report-only mode.
4. Enable policy-driven routing only after benchmark and smoke evidence is good.

Rationale:

- 0.5.1 already shipped the critical model invocation control plane: invocation specs, fingerprinted artifacts, model leases, runtime profiles, queue pump, long Insight map/reduce, and path-safe runtime logs.
- Task-level policy changes affect cache identity and model selection. They should not be mixed into a just-released baseline without evidence.
- Model development is moving fast, so the next durable investment is a measurement and capability layer, not a hard-coded switch to a single new model or backend.

## 0.5.1 Baseline

- `package.json` version is `0.5.1`.
- Tag `v0.5.1` points at the release commit.
- Runtime logs no longer write local absolute paths for:
  - `queue_list_empty.home`
  - `waveform_spawn.audioPath`
  - `vad_session_init.path`
- Core model pipeline is expected to work with Qwen3 GGUF via llama.cpp:
  - translate
  - polish
  - Insight
  - fingerprinted Insight artifacts
  - model-specific sidecar lease
  - hardware-aware runtime profile

If any of these regress, stop this plan and ship a patch release before continuing.
