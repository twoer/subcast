在找**飞书妙记**、**通义听悟**这类云端转写工具的替代品？Subcast 把整条链路搬到了本地：

| | Subcast | 云端转写工具 |
| --- | --- | --- |
| 音视频文件 | 全程留在本机 | 需上传到服务器 |
| 费用 | 免费，无时长限制 | 订阅或时长额度 |
| 联网 | 仅下载模型时需要 | 全程需要 |
| 账号 | 无需注册 | 通常需要登录 |
| 输出 | 双语字幕 VTT / SRT / TXT + AI 摘要 | 视产品而定 |

适合播客转文字、会议记录、网课笔记、访谈整理、视频字幕制作等场景。macOS Apple Silicon 可用，Windows 开发中。
