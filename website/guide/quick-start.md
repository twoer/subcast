# 快速上手

从下载到看到字幕，不超过两分钟。

## 1. 完成首次设置向导

首次启动会进入设置向导：

- **第一步 · 转写引擎**：默认推荐 SenseVoice（内置已就绪，直接「下一步」）。需要 99 种语言或词级时间戳时切换到 Whisper 并选择档位下载。
- **第二步 · AI 模型**：下载 Qwen3 翻译模型，按内存推荐档位（8 GB → 4B，16 GB → 8B，32 GB → 14B）。跳过也可以，之后再在设置中下载。

## 2. 拖入视频

把视频或音频文件拖进窗口（或点击右上角导入），转写自动开始。转写过程中就能开始观看——字幕是流式出现的。

支持 URL 导入：粘贴视频链接，本地 yt-dlp 侧车负责拉取。

## 3. 翻译 / 摘要

- **翻译**：播放器中选择目标语言，本地 Qwen3 翻译，完成后双语字幕实时切换；
- **摘要**：一键生成 AI 摘要与可点击的章节标记。

## 4. 导出

单语 / 双语字幕一键导出为 VTT / SRT / TXT。
