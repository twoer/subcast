# 转写引擎

Subcast 内置两个本地转写引擎，默认以 `auto` 模式按音频语言自动分发。

## 引擎对比

| | SenseVoice | Whisper |
|---|---|---|
| 语言 | 中 / 英 / 日 / 韩 / 粤 | 99 种语言 |
| 速度 | CPU 上约快 15 倍 | 慢（档位越高越慢） |
| 中文准确率 | 优 | 档位较低时一般 |
| 字幕粒度 | 句级（VAD 分段） | 词级时间戳 |
| 模型体积 | 250 MB（内置） | 77 MB – 1.6 GB（按需下载） |

## auto 自动分发

默认模式。每个任务开始时采样开头几秒语音投票判定语言：

- **中文 / 日文 / 韩文** → SenseVoice（锁定该语言，快且准）
- **英文** → 已下载 Whisper 模型则走 Whisper（词级时间戳），否则 SenseVoice 锁定英文

整个任务使用同一种语言，杜绝一段转写里中英夹杂。解析结果会记录在任务历史里（`auto → sensevoice` 等）。

## 手动指定

设置 → 模型 → 转写引擎，可固定为 `SenseVoice` 或 `Whisper`。

## 其他能力

- **VAD 分片**：Silero VAD 预分段，只处理真正的人声，长视频提速 30–50%；
- **断点续跑**：任务中断后重新打开自动从断点继续；
- **重新转写**：切换引擎或模型后，对已有视频可一键重新转写。
