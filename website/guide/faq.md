# 常见问题

## 首次打开提示「已损坏」怎么办？

macOS Gatekeeper 对未签名 app 的拦截，不是真的损坏。终端执行：

```bash
xattr -cr /Applications/Subcast.app
```

## 数据会离开我的电脑吗？

不会。转写、翻译、摘要全部在本机运行。首次下载模型需要联网，之后完全离线。无遥测、无上报。

## 和飞书妙记、通义听悟等云端转写有什么区别？

Subcast 是本地离线方案：音视频不上传、无需账号、无遥测，转写 / 翻译 / 摘要全部在本机运行，也没有时长额度或订阅。云端工具则依赖服务器，通常按订阅或时长计费。对隐私敏感（会议、访谈、内部材料）或素材量大的用户，Subcast 可以当作飞书妙记、通义听悟的免费本地平替。

## 翻译和摘要需要什么配置？

首次使用需下载 Qwen3 模型：8 GB 内存推荐 4B（2.5 GB），16 GB 推荐 8B（5 GB），32 GB 可用 14B（9 GB）。仅转写不开 AI 功能的话，8 GB 内存的 Mac 也能流畅使用。

## 转写结果出现中英混合？

不会——每个任务自动锁定单一语言。若对英文内容识别质量不满意，在设置中下载 Whisper 模型（推荐 large-v3-turbo），auto 模式会让英文音频自动走 Whisper。

## 提示「转写组件未就绪」？

模型文件不完整或被删除。到 设置 → 模型 重新下载对应模型即可。

## 支持 Windows 吗？

正在开发中。当前仅支持 macOS Apple Silicon。

## 开源吗？免费吗？

Apache-2.0 开源协议，完全免费，无任何付费功能或订阅。
